# TNY-013 — Public price evidence interface

- **Status:** Proposed / not started
- **Specification:** [Implementation Specification v1](../specs/implementation-spec-v1.md)
- **Dependencies:** `TNY-008`, `TNY-009`

## Objective
Expose price estimates with context, evidence quality, and limitations.

## Tasks
- Show location, item/category, period, freshness, count, median/range, coverage, evidence tier, and limitations where available.
- Distinguish current estimates, historical data, basket cost, and official inflation statistics.
- Explain suppressed/unavailable estimates instead of fabricating values.
- Show contextual price-shock alerts only from validated evidence and approved alert logic.

## Acceptance criteria
- UI tests cover fresh, stale, insufficient, and conflicting evidence.
- One report cannot produce a market-wide claim.
- Accessibility/responsive checks are performed where supported.
- Production-facing values trace to service/API data, not hard-coded illustrative fixtures.
