# TNY-004 — Authentication and authorization

- **Status:** Proposed / not started
- **Specification:** [Implementation Specification v1](../specs/implementation-spec-v1.md)
- **Dependencies:** `TNY-003`

## Objective
Implement or verify identity and least-privilege access controls.

## Tasks
- Map roles to operations and records; enforce authorization in service/API and data boundaries.
- Restrict contributor identity and enforcement/appeal data.
- Implement or verify privileged TOTP 2FA, recovery, session invalidation, inactivity controls, and sensitive-action reauthentication as supported by policy.
- Keep unresolved timing/throttling values configurable or gated.

## Acceptance criteria
- Tests cover anonymous access, wrong role, cross-user access, privilege escalation, revoked/suspended sessions, and sensitive data access.
- Privileged recovery does not rely on SMS as sole factor.
- Security events are logged without credentials, tokens, or recovery codes.
- Unresolved values are not silently assigned.
