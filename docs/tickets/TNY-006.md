# TNY-006 — Validation and freshness rules

- **Status:** Proposed / not started
- **Specification:** [Implementation Specification v1](../specs/implementation-spec-v1.md)
- **Dependencies:** `TNY-005`

## Objective
Apply validation and freshness eligibility before observations affect current estimates.

## Tasks
- Apply 14-day maximum age to food, transport, cooking fuel; 45-day maximum age to housing and utilities.
- Preserve observation time; never make stale data appear fresh.
- Flag suspicious/incomplete/unusually large changes for review, not automatic guilt.
- Prevent comparison of incompatible units, variants, routes, periods, or context.
- Keep stale observations for valid history while excluding them from current estimates.

## Acceptance criteria
- Tests cover freshness boundaries, future/missing timestamps, time zones, and incompatible data.
- Pending, rejected, incompatible, and stale observations do not contribute to current estimates.
- Genuine large changes can proceed through evidence-based review.
- Unapproved thresholds remain unresolved.
