# TNY-010 — Household affordability engine

- **Status:** Proposed / not started
- **Specification:** [Implementation Specification v1](../specs/implementation-spec-v1.md)
- **Dependencies:** `TNY-003`

## Objective
Calculate affordability from explicit household scenario inputs.

## Tasks
- Separate resources and actual expenses from standard basket estimates.
- Model remittances separately; distinguish received from expected and support regular/irregular/reduced/stopped scenarios.
- Model debt repayments as an expense, not a full debt-management product.
- Calculate surplus/deficit and quantify user-selected alternatives.
- Identify essential versus potentially adjustable expenses without choosing for the user.

## Acceptance criteria
- Unit tests cover zero/positive/negative balances, missing inputs, irregular resources, debt, and alternatives.
- Original inputs are preserved while exploring alternatives.
- Reduced consumption is not treated as better basket-price performance.
- Assumptions/limitations are visible to the interface.
