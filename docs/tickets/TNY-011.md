# TNY-011 — Savings and purchasing-power engine

- **Status:** Proposed / not started
- **Specification:** [Implementation Specification v1](../specs/implementation-spec-v1.md)
- **Dependencies:** `TNY-003`, `TNY-012`

## Objective
Implement transparent savings projections subject to return-policy gates.

## Tasks
- Model initial savings, contributions/frequency, duration, and approved return assumption.
- Calculate nominal balance and purchasing power in today's terms with consistent periods and documented conventions.
- Support emergency-reserve targets and budget feasibility; reserve remains part of total savings.
- Support overall inflation and category-specific overrides where policy/evidence permits.
- Document return/contribution timing, compounding, rounding, and formulas.

## Acceptance criteria
- Tests use hand-checkable fixtures and cover period consistency and reserve accounting.
- An unapproved return rate never silently generates a standard projection.
- User overrides are labeled and recalculate dependent outputs.
- Projections are described as estimates, not guarantees.
